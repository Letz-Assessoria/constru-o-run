# Construção Run · Treinos com a Letz

Plataforma de treinos para a Construção Run 5 km (20/12/2026, São João · PE), com o Programa de 40 dias da Letz Assessoria.

- `index.html`: o site completo, pronto para publicar (imagens embutidas).
- `fonte/`: estilo e abertura (`head.html`) e o script do app (`app.js`), com os treinos em `PLANO`.
- `imagens/`: artes usadas (Letzbora correndo e fazendo paz, logo da Letz, medalha).
